## **Slide 11: Technical Architecture**
### **The 3-Plane Model for Enterprise Robustness**
**Key Message:** A secure, scalable, and decoupled foundation.
- **Data Plane (Read-Only):** Strictly enforced read-only access via **FastMCP** for real-time SQL synthesis and connector-less integration.
- **Consolidation Intelligence:** Advanced semantic joins in the Intelligence Plane using **Go/Genkit** to merge data from disparate sources.
- **Intelligence Plane:** Proactive reasoning powered by **Go/Genkit flows** with explicit input/output contracts.
- **Action Plane:** Human-In-The-Loop (HITL) mandatory for all external write-backs, logged to an immutable audit trail.
- **Visual Suggestion:** A layered architecture diagram (Top to Bottom: Action, Intelligence, Data) with glassmorphism effects and glow indicators for data flows.
